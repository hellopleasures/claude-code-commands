# Plan & Research

Before writing any code, analyze the problem space thoroughly.

## Requirements

1. **Clarify the goal** — what exactly needs to be built and why
2. **Identify constraints** — dependencies, edge cases, and limitations
3. **Research existing patterns** — check what APIs, libraries, or existing code applies
4. **Outline the architecture** — data flow, component structure, API design
5. **List unknowns and risks** — what could go wrong, what needs clarification

## Rules

- Do NOT simplify anything or stub it
- Do NOT proceed if requirements are ambiguous — ask clarifying questions first
- Research the existing codebase before proposing new patterns
- Consider the project's architecture defined in CLAUDE.md

## Deliverable

A written plan that includes:
- Clear problem statement
- Proposed solution with rationale
- Files to be created/modified
- Potential risks and mitigations
- Questions that need answers before implementation

Wait for approval before proceeding to implementation.
